# 资产与模型

## U盘资料与GitHub仓库

U盘里的“视频转白模工具箱”是用户自己的完整复用资料副本，包含通用工具、私有模板、历史场景、参考素材和已下载的算法权重。这个GitHub仓库保存通用主工作流、工具源码、插件和使用说明，便于查阅、更新与复用。

客户人物模板、原始附件、参考视频、Blender工程、私有profile、真实角色对应关系和内部失败媒体按项目原要求留在本地。仓库内的测试模型和输入均为合成数据；测试假文件不能用作实际人物或输入视频。

其他独立网页项目不属于视频转白模的主流程，也未加入本仓库。

## 动作算法和大文件

动作算法、权重及其许可按本项目的[动作工作流](../references/motion-workflow.md)部署。GEM-X代码来源为[NVlabs/GEM-X](https://github.com/NVlabs/GEM-X)，相关模型来源为[NVIDIA GEM-X](https://huggingface.co/nvidia/GEM-X)与[NVIDIA SOMA-X](https://huggingface.co/nvidia/SOMA-X)。复用前读取对应许可和适用条件。

GitHub普通Git仓库会拒绝超过100 MiB的文件；大文件需要Git LFS或其他适合的分发方式。本仓库通过上游来源说明获取模型，不把数GB权重、旧虚拟环境或下载缓存提交进Git历史。参见[GitHub大文件说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。

本机已有权重可按上游工具要求复用，但仍须核对来源、内容校验和目标电脑的依赖；不能因文件存在就宣称推理或动作已通过。

## 配置与来源

复制到新电脑后，重新选择 Python、Blender、FFmpeg、技能目录及模型路径。不要上传包含凭据的配置。私有模板和候选映射留在独立本地目录，通过工具参数明确指定。

`source-manifest.json`记录工具来源提交、文件SHA-256和必要的测试目录适配。它证明整理时的来源，不代表上游最新版本，也不代替实际安装与生产验收。
