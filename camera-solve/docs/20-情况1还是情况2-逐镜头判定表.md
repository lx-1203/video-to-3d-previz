# 情况1 还是 情况2 —— 逐镜头判定表

> **任务**：变焦推 + 摄影机后拉，两个运动抵消，主体视觉大小不变。
> 需要分辨是 **情况1（焦距不变·摄影机近）** 还是 **情况2（焦距长·摄影机远）**。
> 两者成像是**一样大**的，唯一可靠的区分依据是 **绝对焦距**（→ 等效视角）。
>
> **口径**：vfov ≥ 45° → 情况1；vfov ≤ 30° → 情况2；30–45° → 两者之间。
> （60° 以上已是超广角；30° 以下典型长焦。阈值可在 `src/focal_fusion.py` 调。）

## 三、判定不了的原因分布

- 画面里没有可用几何信息（无相机运动 / 无正交透视线 / 无人脸 / 太暗）：**43** 个
- 只有学习模型估计（本片实测偏 −22%~−55%，不采用）：**10** 个
- 切分不可信（段内有硬切，或段内 f 漂移无法解释）：**7** 个
- done：**6** 个
- 只有相对倍率，没有绝对焦距 —— 判不了是哪种：**5** 个

## 四、对「旁边物品进入镜头」的影响

既然**已测出的镜头全部落在情况2或中间带，没有一个判为情况1**，那么：

1. **相机离主体很远**，进入画面的道具（桌角、路沿、路人）相对于相机也比
   「广角近拍」时更远 —— 它们的**放大倍率没有那么大**。
2. 真正会毁掉重建的不是「物体太大」，而是 **焦距填错导致的深度错位**：
   长焦镜头真实 f 很大（本片实测 f ≈ 1142–2383 px@720，等效 vfov 17–35°）。
   如果管线按常见默认（约 50° 视角）去重建，道具的深度会被**系统性拉近**，
   于是「道具穿过人物 / 道具被放到脚前」这类错误就出现了。
3. ⇒ **把上表的绝对 f 填进去，这一类错误会直接消失**，而不是靠后期修补。

> 换句话说：你们观察到的「道具进镜头就影响效果」，
> 在主因上不是取景问题，而是**焦距没对上**。
