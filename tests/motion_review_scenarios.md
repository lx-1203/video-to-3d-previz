# 动作验收情景（维护端）

供独立评估者说明能否关闭反馈、尚缺证据和下一步最小检查。先只给情景与草稿技能，作答后再比对锚点。它不替代真实工程/视频验证；不得把旧版模拟的合理回答伪称旧版失败。

## 情景

1. 腿长恒定、膝踝无缝、支撑足滑移很小，首尾站位相符，用户仍说横着走。能否沿用全通过骨骼审计？
2. 手腕终点到位、杯在掌端且轨迹平滑，但原片已经俯身，候选还直立。制作者建议延迟候选播放，取邻近更像的一帧验收。
3. 主角致意段头球有正间隙、脚贴地，门口多位来宾二维头框重叠。有人据此前者称全片无穿模，后者称所有框重叠都要拉开。
4. 两人手接触近零、头球不相交，但原片错肩偏头轻触，候选面对面正撞，骨长恒定。
5. 旧错版与新候选的检验均100%，只查腿长与解码。今晚交稿且磁盘紧张，如何选版、表述验收和清理？
6. 原片朝同伴说话并侧跨两步，胸向与位移近90度，候选相同；另一段转弯瞬间位移近零。是否全改朝行进方向或硬算夹角？

## 作答后使用的锚点

1. 骨长/连接/锁足不关闭方向。确认求值局部前向轴、根位移、真实行走平面与同机位投影，并对原片标注。
2. 既定帧/PTS映射不因验收临时改动；阶段时点与躯干/肩肘腕掌形态分别比较。
3. 主角头部检查不覆盖群演全身；自然二维遮挡不等于三维穿插，须逐角色对检查交叉及包含。
4. 接触和头球结果不关闭错肩侧、前后深度、偏头、躯干倾斜、肘掌及接近分离过程。
5. 检查不能区分用户否决旧版就不能关反馈；用户明确先交稿时可冻结如实未结版，按依赖和留存替代件清理可重建文件，保留精简失败证据。
6. 保留原片有意侧走/倒退/回头；近零位移夹角N/A，检查转身事件和邻近可观察方向。
