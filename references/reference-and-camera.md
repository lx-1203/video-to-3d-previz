# 原片拆解、空间和机位

## 帧与镜头基准

同时记录 source_frame（解码零基序号）、source_pts/time、Blender_frame 和 shot_id。常帧率且没有剪辑时 `time=i/fps`，Blender通常从1开始；可变帧率、不同起点或变速必须使用显式时间映射，不能套用加1。

逐镜标注切点，不跨硬切插值相机。每镜取首尾、代表性中间帧、重要遮挡帧，并在动作附近加密。固定审查帧后不因候选表现差而删换；优化用过的帧不再称作未见测试帧。

每个标注带来源图、坐标、置信区间及可见性。参考和候选统一等比到同一坐标系，不用裁切、平移、透视校正或选“最像的一帧”来提高分数。用于制作分析的裁剪局部可以保存，但不能伪装成全画幅验收。

## 空间先看连接与遮挡

不要从单张截图直接堆一排椅子。对完整镜头建立这些关系：

| 对象 | 需要回答 |
|---|---|
| 地面/楼层 | 哪块地面承托哪个人？有哪些高差？上层和下层是否独立？ |
| 走道 | 宽度、转向、连通区域在哪里？人物转弯后是否仍在有效地面上？ |
| 挑空/转角 | 前后两条边怎样相交？角点随相机向哪侧出画？ |
| 挡墙/楼板 | 是否有可见厚度、深度和上下边界？遮住了哪些下层物体？ |
| 栏杆 | 起止、转折、立柱间距与人物的前后关系如何变化？ |
| 座席/墙/楼梯 | 行列退深、倾斜方向、过道和层间遮挡是否一致？ |

影院案例的关键是“上层通行带围绕挑空转折，深挡墙真实遮挡下层座席”。只有一段直栏杆或薄板，即使头部坐标很准，也不能通过空间门槛。

先用简明体块和多帧投影确定拓扑，再细化座椅阵列。必须留真实可行走空间；不能为贴合座席画面而把座椅挤进人物路径。无画面依据的隐藏结构只做满足场景的最小合理建模，标为推断。

门洞随镜头变化总是对不上时，先辨认是否为连续多拱、厚柱与邻接餐区，而非继续平移唯一门洞。用转身/走远镜头和吧台侧机等不同视角核对柱间视差、开口数量与遮挡；保留已有证据支持的主拱，再补缺失的相邻结构。拱后应有能产生正确遮挡与视差的通透深度，按可见范围简化地面、桌椅或暗部空间；一张黑面或彼此封闭的窄盒不能替代原片可见的相通区域。

## 场景主色与逐镜背景

先按用户要求区分灰模、语义配色和原片还色。已要求还色时，从原片登记木饰面/墙、地面、座椅、栏杆、吧台、沙发、窗帘和吊顶等可见主色块及明暗关系；只做角色彩色而环境全灰不算还色。旧案例的“前景棕、背景灰”是另一种表达方式，不能覆盖本轮明确的原片颜色要求。简模不必复制所有纹理，但主要色块、材质冷暖和照明观感须可辨认。

分别检查材质输入与实际输出：渲染引擎、Workbench 的 color_type/single_color、视图材质覆盖、View Layer 的 material_override、合成节点、灯光、曝光和色彩管理。按当前引擎修改真正生效的设置，不要求一律换引擎。不能仅修改 Material.diffuse_color 或未连入着色器的 Base Color 后就报通过。用当前工程的同机位渲染及最终视频核对，避免视口彩色而成片仍白、过曝发白或高光冒充底色。

逐镜列出关键背景物、所在墙面/方向、高度、前后层级与可见性，特别是门洞朝向和高度、吧台/自助餐台、酒瓶/果盘、沙发、窗帘、桌椅及吊顶。反向镜头不能继续套同一张通用背景；门洞有一个拱形轮廓不代表方向、高度和通行关系正确。参考中应被遮住的桌面、家具和门框也要登记，不能因为它“场景里确实有”就允许它在错误机位露出。

色彩取样注明是否来自受光的图像，不把截图显示色直接当作物体真实材质色。最终以同时间、同构图的可见色块和明暗关系比较，不为凑像素分数改变参考画幅。

## 相机拟合顺序

1. 以稳定建筑边线、角点、地平线和遮挡顺序约束相机高度、朝向、焦距与运动。
2. 建筑基本正确后，按角色头部中心、肩中心、躯干轮廓和可见脚点拟合人物站位。
3. 固定角色尺度，联动复查机位、人物深度和通行空间。不得用每帧变大变小替代运动解算。
4. 最后检查近景栏杆进入时点、栏杆画内断头、挡墙占比和下层可见范围等细节。

显式核对俯视/平视/仰视：结合桌面露出量、座椅顶面、吊顶占比和背景竖线确定相机高度与俯仰，不能只对齐主角头部。原片略俯视时不能交成平视。用座椅、栏杆、门框等稳定尺度参照，同时复核人物画面占比、深度、角色间距与是否过度贴近；下层或远处人物不能因单独缩放而异常巨大。投影重叠与真实接触分别检查。

二维投影存在多解；不要声称已经还原真实焦距、真人尺寸或不可见建筑施工结构。用多帧与真实支撑关系约束，留下必要的不确定性。

对接近180°的旋转、相机轴变化、关键帧曲线过冲，检查中间帧而不只看两端。角度插值引起的瞬时跳变必须在连续序列里排查。相机变化后，重新核对之前被遮挡的身体、标记及道具。

## 人物与事件表

角色建立稳定ID和身份色；相同颜色但身份不确定时单独标注，不能凭颜色推断同一人。每个事件记录：动作发起者、左右侧、开始/完成帧区间、接触目标、遮挡物、接触建立/保持/释放条件。

取物示例：空手行走 → 抬手 → 伸入对侧衣襟 → 手/物被衣服遮挡 → 物件边缘露出 → 向下抽出 → 转腕 → 单手托持 → 对方接触 → 后续持有关系。看不清是否完全释放时，禁止补造“已松手”。

握手示例：除共同接触点，还要测双方各自肩、肘、腕的位置与上臂/前臂方向。两人的姿态可能不对称，不能把两条胳膊镜像成同一角度。

行走、离画、转身、挥手、张臂和贴面致意也须列事件链：起点/终点、发生时段、根路径、胸背方向、头向/视线、左右手与接触目标分别标注。参考已经走开不能让角色原地摆臂；张臂不能只拟合腕点而把掌心、肘形或左右侧做反。截图只能证明局部姿态，无法确定的时序须回原视频读取，不能编造精确帧号。

## 原片证据的质量

自动识别结果需要覆盖图复查：同色头部和躯干可能粘连，肩宽可能误把前臂算进去，暗部道具可能与背景合并。记录可观察轮廓定义，不在得分不利时更换定义。

原片有遮挡的点可记 N/A；候选把原片本应可见的关键物件遮没了是错误，不能也记 N/A。只记录能从视频支持的动作顺序和时间区间。
