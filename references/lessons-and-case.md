# 已踩过的坑与来源案例

此文件将实际制作错误整理为可复用检查。案例已匿名化，不提供原项目当前状态，也不把历史局部验收当作新任务的通过证据。

## 失败模式、原因与防复发

| 已出现的坑 | 原因/误判 | 下次的具体动作 |
|---|---|---|
| 上下层影院被读成一层座椅 | 只拟合头部位置和一条栏杆 | 先验楼层、挑空、转角、深挡墙及真实遮挡 |
| 直墙或T形回廊代替原片转角 | 几何拓扑错误，却继续调焦距 | 用多帧角点轨迹和连接关系重建，先过结构门槛 |
| 座椅占用走道、人物出界 | 图像拟合没约束物理通行区 | 检查真实楼板联合区域和整段人物路径 |
| 栏杆提前入画、画内断头 | 单帧位置对了，长度/方向和时序没查 | 跨入画/出画边界逐帧检查 |
| 相机中途跳动 | 旋转或曲线插值没有看中间帧 | 检查连续轨迹、角度绕转及切点 |
| 建筑重叠面出现闪纹 | 重建残留共面几何 | 查看实际渲染并清理重复面/层叠 |
| 眼条落在嘴部 | 把装饰条当成脸部任意标记 | 用头部局部坐标确认眼高，再看实际4K机位 |
| 标记变眼罩、头带或凸起 | 误解“贴面短条” | 采用球面材质分区/贴合表面，确认无侧边框 |
| 眼睛成为悬浮的外置平板 | 仅平移平板使中心碰到球，正面掩盖翘边 | 优先复用认可模型的球面材质分区；查侧视、转头与独立网格边缘离面 |
| 要求场景还色，成片仍灰白 | 把“白模”当成全灰要求，或只改材质槽 | 分离环境还色与角色身份色；核查实际引擎、颜色覆盖、灯光和最终视频 |
| 材质面板灰，节点有色，或反过来 | 混淆viewport diffuse、节点Base Color与Workbench颜色来源 | 读取真正生效的着色路径，用同配置试渲证明颜色输出 |
| 眼条和胸标固定黄色，黄色人物的焦点混在底色里 | 把标记色与角色身份色绑定，未读取实际材质 | 自动计算互补/对立色，核验亮暗与实际画面，同底色跨镜稳定复用 |
| 背部出现胸前黄标 | 胸背轴或标记位置错误 | 检查身体正面轴，标记只附着胸面 |
| 风格修好了却退回旧空间 | 侧聊导出的旧基线直接覆盖主版 | 用输入SHA确认祖先，整合样式并查非目标变化 |
| 一开始已经双手捧物 | 只复制动作终态，漏掉取物过程 | 建立空手到入襟再单手抽出的事件链 |
| 左右手做反 | 骨骼.R/.L与解剖方向相反 | 为当前rig建立明确映射，不能按后缀猜 |
| 取物突然出现或过早露白 | 用显隐掩盖，或衣壳遮挡不够 | 真实开口与逐步显露，检查首次可见边界 |
| 白包穿腰/腿/衣襟 | 旧实心腰块、二维看着接近却路径相撞 | 建衣内空间，检查全部相关网格和全过程 |
| 另一手莫名托住 | 默认对称双手姿态替代原片 | 空闲手独立按原片运动，不自动加接触 |
| 交接提前数帧 | 凭姿态猜首触，没有事件基准 | 锁定原片首触区间，复核接近、首触、保持 |
| 头朝左但身体仍正对镜头 | 只转头未改肩胸骨盆 | 全躯干与支撑点一起调整 |
| 修侧身后头悬空、肘有缝 | 旧连接缝被暴露或父级缩放影响 | 重开求值，测头肩/肩肘腕连接并查实际轮廓 |
| 为补浮头擅加圆柱脖子 | 把连接问题当作增添外形的许可 | 已确认无颈样式时修位置、枢轴、绑定和内部连接；转头/俯身后仍无缝无外露颈柱 |
| 球、圆盘代替手，臂长止于腕点 | 手型未对照认可模型，只追末端接触点 | 按参考锁定肩肘腕掌端全链与平整/块状掌形，不自动加球手或写实五指 |
| 两手握住却手臂姿态错 | 接触距离通过不代表肩肘腕正确 | 原片独立角度和肘极向测试，旧错版作反例 |
| 手臂逐帧变长 | 用缩放追接触点 | 整镜固定比例与骨长约束；残差不得隐去 |
| 人物走路僵硬、滑步或该离画却不走 | 只做首尾位置或原地摆臂 | 连续核对根路径、支撑脚、重心、步频、摆臂及离画时间 |
| 挥手、张臂、贴面致意都套默认姿态 | 只对两端关键帧或接触点 | 按原片检查起势至收回，分别核对躯干、偏头、肘形、掌心及接触部位 |
| 应有手持物却只做空手 | 以腕点到位代替道具建模和持有 | 建可辨认轮廓，核查出现时间、持有者、掌托区域及实际可见性 |
| 人物互穿或距离近到挤在一起 | 二维投影靠近被当作正确三维接触 | 复查真实间距与人物间表面，覆盖接近、保持、分离及邻帧 |
| 下层/远处人物过大 | 单独缩放人物补投影，没有稳定尺度参照 | 用座椅、栏杆、门框校准尺度与深度，再核对画面占比 |
| 原片略俯视却交成平视，桌子额外露出 | 只对齐头部，漏看桌面与吊顶占比 | 联合检查机位高度、俯仰、焦距及应露/应遮物 |
| 门洞方向/高度、反打背景仍错 | 通用布景轮廓替代逐镜空间核对 | 按每镜登记门洞所在墙面、朝向、高度和关键家具/背景层级 |
| 吧台侧机单拱看着对，走远镜头却是大平墙 | 连续拱廊被简化成一个门洞，误以为继续移门就能拟合 | 多机位先核对邻拱、厚柱及拱后相通空间，再调局部位置 |
| 共享脚本修了，但另一模型仍是旧错版 | 没有逐实例映射和重新导出 | 模型/角色/镜头/否决项逐条绑定当前工程、渲染和成片证据 |
| 只测内衬就称零穿插 | 检查范围遗漏外襟或其他身体部位 | 报出每类对象覆盖；未知与已通过分开 |
| 结构检查很多就称95% | 用技术项数量替代观感和动作 | 四层验收分开，未知动作项不填100 |
| 建筑99分包装成全片95% | 平均分掩盖弱角色和缺失维度 | 每角色/每镜门槛、误差区间、完整动作证据 |
| 为了过线变抽样、调阈值 | 评价与优化没有分离 | 冻结协议，保留失败帧与协议版本 |
| 旧成片被当成新修订 | 没核对工程-渲染-编码链 | 绑定SHA，并检查最终MP4的修改区域 |
| 包报告的路径和SHA都通过，实际交付仍选错版 | 只验证报告自己的引用，缺少当前选择依据 | 对照实际选中工程、帧清单、媒体和入口逐项匹配 |
| WAV打包了但外部路径失效 | 另存自动重写相对路径 | 保存后重开，同时验证packed和外部副本 |
| 请求高AAC码率仍不达标 | 把目标参数当实测结果 | 真实素材试编并统计音频包实际码率 |
| 原声尾部被截掉/出现双重声音 | 无条件shortest或两轨相加 | 只用一份音轨封装，分别核对音画尾部 |
| 4K渲染中磁盘耗尽 | 旧可再生PNG长期累积 | 用实际样本估量，验证保留件后清明确缓存 |
| 维护技能放桌面被误删 | 发布技能依赖不明显的桌面源 | 技能独立放长期目录，备份并记录来源 |
| 无法启动播放器却说已回看 | 用解码/联系表冒充GUI播放 | 分别写实际做过的检查；不可用项保留未验证 |
| OCR失败却被汇总成通过 | 工具未执行与人工复核混同 | 记录失败原因和人工范围，明确OCR未运行 |
| 肩线被当成腰到肩的长轴，越拟合越错 | 根据画面长边或头部邻接替用户定义解剖方向 | 先记录线段语义；用户明确解释覆盖旧推断，不以拉长脊柱追肩宽 |
| 手绘盒角对齐，身体仍多出骨盆/腿块 | 混用胸段、整体躯干和衣物包络，单线分数替代真实轮廓 | 明确拟合对象，突出块用对象ID辨认，核对整个人体与邻帧 |
| 头胸间隙很小，头却被身体挡没 | 最近距离只证明局部接近 | 连接、深埋、头部可见性及原片遮挡分别检查 |
| 对照截图上下栏越量越偏 | 播放器放大裁边，两栏局部原点不同 | 定位同帧与截图变换，再回原片完整画幅；红框不直接当物体精确边界 |
| 圆桌位置接近，四椅却朝外或脚点错位 | 只对齐桌面或人物头部 | 联查桌面、底盘、椅背/座面/脚、沙发与门，从实际几何判朝向 |
| 相机与人物同移后投影没变，却撞家具 | 相对投影不代表世界通道不变 | 回归受影响镜头、真实地面和全段动线，包括离画到再入画 |
| 隐藏路径每帧都可行，连起来仍跳位 | 无依据旧站位当硬约束，逐帧贪心选点 | 标明推定，检查连续路线与速度，接回可见动作，不藏物体换零碰撞 |
| 已被要求赶快导出，还在开新候选 | 把修完全部目标置于当前停止指令之上 | 停止新增试修、通知协作者、逐片冻结；按原规格导出并明示未结项 |
| 为赶稿把unverified改passed，或把旧版称新修 | 混淆交稿许可、视觉结论与源版本 | 单独登记部分交稿选择，保留原报告状态，工程与成片逐片对应 |
| 播放器结束被写成全程回看/试听通过 | 软件播放状态被当成人工观察证据 | 分开记录实际观察范围、解码检查与播放器状态 |
| 旧动作未改就被当成当前动作正确 | 继承签名只能证明未变，抽样没覆盖新的用户否决项 | 每项重新关联原片帧、角色与判据；旧错版须触发失败 |
| 主角头部接近，胸背和配角站位仍错 | 单点或平均误差掩盖各角色构图 | 躯干正反面独立核对，逐角色比较完整画幅位置/大小/裁边 |
| 零穿插报告漏掉绿角色、肘部或杯子 | 仅对单角色的少量顶点检查躯干 | 预登记角色×肢体×目标×帧段，真实表面与可见轮廓两条证据 |
| 平掌存在但前臂仍没覆盖掌部 | 网格顶点数/骨长通过被误当外轮廓通过 | 依当前模板与用户解释保留掌大小，核对袖口至掌端覆盖 |
| 酒杯/托盘终态完整却突兀出现 | 没看首次可见前后及端入/放置连续段 | 检查真实遮挡、整组路径、支撑与相邻帧，不能显隐补终态 |
| 报告记录穿入样本，汇总却仍零失败 | 异常只进旁路统计，没参与必需项布尔判断 | 用越界反例跑实际汇总/发布路径，异常必须阻止相应验收通过 |
| 只要求取物动作，却把身体拆开外翻 | 无条件套用衣壳开合，越过模板外形与用户动作边界 | 先读模板/当前指令；闭合身体用可证实的手臂动作和遮挡表现 |
| 腿长/膝踝检查通过，人物仍横着走 | 没比较根位移与真实胸/脚前向轴 | 对原片同帧方向关系，保留有意侧走和静止N/A，不统一自动转正 |
| 主角头球有间隙，被写成群演全身无穿模 | 人物、部位与入场帧段覆盖不足 | 完整角色逐对全身检查，二维遮挡与三维交叉/包含分别判断 |
| 腕高或接触通过，挥手/致意阶段与形态仍错 | 缺同帧原片阶段、错肩深度与躯干姿态 | 时点、位置、朝向、形态拆分；不临时挪候选帧凑相似 |

## 1.1.0用户纠正规则

用户明确要求标记色由当前底色自动计算为对立色或互补色，以区分焦点部分；本次更新同时记录第四角色在采用该项目色板时全镜统一黄色。新规则替代历史工程里“统一黄色眼条/胸标”的做法。下面快照中的“黄标”等描述仅记录旧版事实，不是今后的固定配色要求。此次只更新技能规则与备份包，不声称已修改Blender或重导出影片。

## 匿名案例与证据边界

新一轮标注图再次指出环境白灰、外置眼板、浮头、球手、擅加颈柱、机位与背景错误和连续动作偏差。提供的绑定参考中，默认启用主角色的眼条由头部同一网格的材质分区沿球面实现，头身直接衔接，块状前臂延至平整掌端；这说明无需外置立板、球手或外露颈柱也能保持简模风格。是否认可、是否启用及实际材质颜色仍须读取任务中的参考与对象状态，不把文件内所有隐藏/禁用变体一律视作认可模型。

模型编号及对应的原工程、帧号保存在本机修订记录，不随公开技能分发。截图只能支持标注位置的局部事实，不能证明精确穿入深度、骨骼原因、完整时序或修后通过；用户提供样例也不等于已修改其工程。

这些方法来自一个三段参考视频的Blender预演项目，源片均为720p、30fps。早期技术交付通过后，用户继续发现上下层影院、眼条位置、衣内取物、躯干朝向及肘形等视觉错误。因此，文件/编码检查和最终视觉验收必须分层，不把历史通过结论延用到新要求。

一轮候选建筑名义评分99.10，但两个角色约93.93与92.56，动作未完成量化；整体95%仍未证实。后续取物与身体方向修订被接受，也没有自动关闭整体目标。衣服局部无相交不代表所有衣片无相交，修好两帧过伸不代表全部骨段恒长。

握手案例中，旧版两手接触几乎零误差，骨长也稳定，但158个近侧样本均违反原片肘形范围。独立检查肩肘腕方向后才检出问题。这说明验收要能够识别用户否决的旧版，而不是只重复制作函数的输出。

后续修订还遇到三类诊断偏差：换成平掌后旧腕中心误差不再代表掌面接触；支撑脚只锁位置仍会滑转，需连同朝向、固定腿长和换步重心复核；较高PNG压缩未必缩短整段4K渲染。相应方法见[造型与动作](character-and-motion.md)及[交付与音轨](delivery-and-audio.md)。案例测得的滑移、骨长误差、接触间隙和压缩耗时只说明该次模型、设备与样本，不作为其他项目的通用阈值。

肩线案例中，轴向理解纠正后单条肩线的投影改善，实际骨盆、腿与上臂轮廓仍不满足参考。用户随后要求停止补修并交稿，因此保留未结反馈、沿用明确标版的旧成片；没有将失败候选当作成功解法。这里新增的是诊断和交稿规则，不是已验证能还原该身体的参数配方。

原项目曾因桌面上的技能维护源误删而无法同步；恢复必须明确备份来源、验证完整性并遵守原同步规则，不可冒称恢复了未保存改动或Git历史。播放器或OCR不可用时，保留实际失败记录，人工审图不能改名为播放/OCR通过。
