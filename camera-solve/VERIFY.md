# 自检清单（跑完请把最后那行贴回来）

目标：**5 分钟内确认接口通不通、两边的 f 有没有打架。**

---

## 第 0 步：装插件

把 `addon/` 整个文件夹拷到：

```
%APPDATA%\Blender Foundation\Blender\<版本>\scripts\addons\camera_solve_addon\
```

或在 Blender → Preferences → Add-ons → Install，选 `addon/__init__.py`。
装完在 **N 面板 → CameraSolve** 标签。

> 要求 Blender **3.6+**。插件只用 bpy 标准 API，不装任何第三方包。

## 第 1 步：解压交付包

把 `handover/camera_solve_2026-11-09.zip` 解压到任意目录，得到：

```
camera_solve/
  0.camera_solve.json
  ...
  d9645e46aeba9077.camera_solve.json
```

## 第 2 步：读 JSON

面板里：

| 字段 | 填什么 |
|---|---|
| `camera_solve 目录` | 指向上面解压出的 `camera_solve/` |
| `sensor 约定` | `Super 35 24.89mm`（哪个都行，不影响视角，只影响 mm 数字） |
| `源帧率` / `Blender 帧率` | 都填 `0`（表示用 JSON 里的帧率） |
| `frame_start` | `1` |

点 **读取 camera_solve JSON**。

**预期**：弹出 `读到 54 镜头，可写 9`。

## 第 3 步：接口自检（关键一步）

**先选中一个 Camera 物体**，然后点 **接口自检 / 冲突报告**。

**预期输出**（默认状态：相机上还没有 lens 关键帧、lens 是 Blender 默认 50mm）：

```
[CameraSolve] 自检：可写 9 / 冲突 0 / 保留 AI 0 / 无测量 45｜相对曲线 1 个，其中有基准 0
```

> `有基准 0` 是**正常的**：那 1 个"只有相对倍率"的镜头还没有乘数基准，
> 在面板里填一个 `锚点 mm`（第 3.5 步）它就会变成 `有基准 1`。

### 四种结果各代表什么

| 结果 | 含义 | 下一步 |
|---|---|---|
| `可写 9 / 冲突 0` | ✅ 接口通，两边的 f 不冲突 | 进第 4 步 |
| `冲突 > 0` | ⚠️ **你们 AI 的 f 和我的测量差 >30%** | **把这行数字贴回来**，我判断是谁的问题 |
| `可写 9 / 保留 AI 9` | 你们已经有 lens 关键帧，当前是"AI 优先"模式 | 想用我的就切 `算法优先` |
| `可写 0` | 目录或格式不对 | 检查是否指到了 `camera_solve/` 这一层 |
| `相对曲线 N 个，有基准 0` | 你们没留 `lens` 关键帧 | 手填一个 `锚点 mm` 即可 |

## 第 3.5 步（可选但推荐）：给"只有相对倍率"的镜头一个锚点

面板 `方案 A` 框里填 `锚点 mm`，比如你们已知某个镜头大概是 20mm，就填 20。

再点一次 **接口自检** → 应变成 `相对曲线 1 个，其中有基准 1`。

> 这一步**不需要等任何人**。填一个数，那个镜头的逐帧绝对 f
> 就由 `基准 × ratio(t)` 算出来了。

## 第 4 步：写入

点 **写入焦距关键帧**。

**预期**：`写 9 个镜头 / 146 个关键帧（相对曲线 0），跳过 0，缺锚点 1`

> 计算方式：`2.mp4` s1 是逐帧曲线（138 帧 → 138 个关键帧），
> 另外 8 个可写镜头各 1 个单点 → 138 + 8 = 146。

## 第 5 步：看效果

时间轴上会多出 `CS:<文件>:s<镜头> <状态>` 标记（点 **建镜头标记**）。
拖动时间轴，相机 `lens` 应该按镜头切换。

---

## 可选：人工覆盖

面板里填 `镜头#` + `lens(mm)` → 该镜头用你填的值。`lens=0` 表示不覆盖。

## 可选：只写采样点（关键帧少一点）

把 `逐帧键` 勾掉 → 只在实测采样点和首尾写关键帧，其余交给 Blender 插值。

1. 第 3 步那行 `自检：…`
2. 第 4 步那行 `写 N 个镜头 / M 个关键帧…`
3. 如果出现 `冲突`，把每个冲突的具体数字贴回来（`算法 xx.xxmm vs AI yy.yymm (diff=zz%)`）

- 你们的 AI 有没有输出 f、和我的差多少
- 那几个"只有相对倍率"的镜头能不能立刻救回来
