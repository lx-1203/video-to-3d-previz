# 安装与使用

## 环境与目录

准备 Python 3.10+、Git、Blender 和 FFmpeg。插件代码声明最低 Blender 4.2，其他版本是否适合具体工程，应在当前电脑上用短段实际检查。媒体处理的外部 Python 需要安装插件说明中列出的依赖。

将上游主技能按其 README 和发布清单安装到当前工具的技能目录。不要把整个上游 Git 仓库直接当作受管安装目录；运行文件必须与上游清单一致。不要照抄旧电脑的 C、D、E 盘绝对路径。

## Blender 插件

1. 下载本仓库 `downloads/orderflow-0.1.0.zip`。
2. Blender → 编辑 → 偏好设置 → 插件 → 从磁盘安装，选择该 ZIP，启用“接单助手 / OrderFlow”。
3. 选择本机 FFmpeg 和外部 Python。动作辅助和正式打包还要选择上游安装目录对应的工作流、在线更新检查和骨架叠加检查脚本。
4. 打开自己的工程并保存，在 3D 视图按 N，进入“接单助手”，设置参考视频、帧段和输出目录。
5. 先检查工程、试渲短段，再处理全片。使用当前保存后重开的工程及实际影片验收。

详细输入约定、取消任务、角色配色、外部库及模拟缓存限制见[插件完整说明](../tools/blender-order-tools/README.md)。

## 便携工具包

`scripts/portable/build_bundle.py` 用于在自己的电脑上把本项目主技能、获授权的私有模板、明确选择的候选 profile 和插件 ZIP 组装成私有便携包。请先看[便携安装说明](../references/order-toolkit.md)和脚本 `--help`。本仓库没有预装客户模型或提供一份对所有人物通用的骨架映射。

生成的私有包完整解压后，按包内 `INSTALL.md` 先运行安装计划，再安装到自己的本地目录。安装器核对文件和路径，不会替你启用插件或执行模型。动作后端和驱动仍须在目标电脑配置。

## 使用门槛

使用 `video-to-3d-previz` 前，每次正常执行其在线更新检查；网络失败、本地冲突或清单不一致时停止该工作流，按上游说明处理。不要绕过更新锁或修改清单冒充通过。

原声、编码、分辨率和帧数核对与动作验收分别办理。正式交稿还要检查当前源对应的同帧骨架叠加、完整动作阶段、三维连接/碰撞和实际画面；没有执行的检查保持未验证。
