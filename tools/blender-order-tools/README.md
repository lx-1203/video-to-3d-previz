# 接单助手 / OrderFlow 0.3.1

在 Blender 的“接单助手”面板设置参考视频、帧段和输出位置，后台生成白模原声影片、同步上下对照，并核验文件。CameraSolve 焦距候选、动作参考和角色配色也在同一面板处理。

原有导出流程在 Windows 的 Blender 5.2.2 LTS 验证。焦距候选在 Blender Python 5.2.3 LTS 验证。代码声明最低 Blender 4.2。插件包只包含代码、说明和配色示例。

## 安装与设置

1. Blender → 编辑 → 偏好设置 → 插件 → 从磁盘安装，选择 `orderflow-0.3.1.zip`，启用“接单助手 / OrderFlow”。
2. 在插件偏好设置中选择 FFmpeg，以及装有 `av`、`numpy`、`Pillow` 的外部 Python。导出前会实际检查这些程序能否运行。交稿打包另须把“动作工作台更新检查”设为已安装主技能的 `scripts/check_update.py`，把骨架检查器设为同目录的 `scripts/validate_skeleton_overlay.py`。
3. 打开已经保存的工程，在 3D 视图按 N，切到“接单助手”。填写订单名、参考视频和有足够空间的输出目录。
4. 起止帧是 Blender 帧号。“参考起点”表示**工程首帧**对应原片的秒数。部分片段还会自动加上起始帧相对工程首帧的时间偏移。

相机留空使用当前活动相机。指定其他相机时，须先在工程中将其设为活动相机；插件保留原有切镜、机位和材质。先点击“检查工程”，再用短段“试渲片段”检查动作、遮挡、颜色和声音。

## 场景与模型

在「场景与模型」选择地面、墙体、带门洞墙体或道具方块，填写宽、深、高，在 3D 游标处生成可编辑白模。墙体和道具从游标高度向上，地面上表面对齐游标。可用「读取集合 → 追加本地集合」从本机 `.blend` 加入指定场景或角色资产。读取附件前关闭 Blender 的自动运行 Python 脚本选项。角色模板和绑定配置沿用本机批准的项目资产。

「本地自动白模流水线」连接机器上现有的 `pipeline_runner.py`。选择已有 Python、场景运行配置和该流水线允许的任务根目录，填原片帧段。可以运行场景估计（包括已配置的 MoGe 几何和相机解算），也可选择场景与人物合成并提供本地角色配置和身份锚。已有任务可直接选择任务目录，通过「核对候选工程」核验原片及 `.blend` 的 SHA，再到「场景与模型」选择要追加的集合。产出是内部制作候选。

## CameraSolve 焦距候选

1. 在订单里选择参考视频、活动相机和导出帧段，填写原片参考起点。展开 **CameraSolve 焦距**，选择对应的 `*.camera_solve.json` 和镜头号。
2. 点 **预览候选** 查看 Blender 帧范围、当前焦距和候选值。只有变焦倍率时，先填该镜头已确认的基准焦距。测量冲突会显示候选供比对。
3. 在工程副本里点 **应用焦距**。插件沿用相机原有传感器、机位和画幅，只为所选镜头生成焦距关键帧，段外恢复原焦距。相机数据已有动画或驱动时保留原效果，可用预览比对。应用后用 **试渲片段** 对照原片的构图和遮挡。

插件使用 CameraSolve 的像素焦距换算及变焦倍率插值。测量 JSON 由订单另行提供。文件声明了原片 SHA-256 时，插件会校验它。现有交接 JSON 依赖参考视频文件名和画幅匹配，核对是否取自同一版原片。

## 多人骨架与身份校正

1. 设置订单参考视频及输出目录，在「多人骨架与身份校正」选择本机后端 JSON、镜头 ID 和原片零基起止帧，再新建任务。复制 `examples/auto-box-backend.json` 到本机并填写 Python、GEM-X、检测权重、姿态权重、SOMA 资产和本片内参。示例路径相对于示例 JSON 所在目录。复用旧 Auto Box 配置时，`config/` 内 JSON 的相对路径仍以原 Auto Box 根目录为准。
2. 点「检测 → 生成审核图 → 查看审核图」，核对轨迹身份。填稳定演员 ID、轨迹号、帧段和看图依据，再确认身份锚。必要时可撤销该轨迹的区间。
3. 点击「推理姿态」。改锚后用「按新锚点补算」，只重新推理受影响的演员和帧，保留其余姿态。仅撤销绑定时移除相应姿态，无须重跑模型。两步从已通过在线更新的动作技能安装目录调用多人推理核心。检测和审核依赖本机媒体 Python、PyAV、FFmpeg 及对应模型环境。后台记录、失败原因和结果保存在当前任务目录。
4. 填原片审核帧号生成原片骨架图，或导入参考骨架。导入按原片 PTS 与当前工程参考起点匹配，骨架在 3D 游标处作为相机空间候选展示，保留实测、补帧和短时保持标记。候选集合仅用于预览，导出时会从后台工程副本移除。正式交稿仍须比对原片与当前白模的同帧骨架证据。

包内 Auto Box 算法源码来自协作分支 `7943e86`。审核图和骨架图接入接单助手配置的 FFmpeg，骨架显示颜色按稳定演员 ID 计算。参考片、示例结果和权重由本机提供。

## 导出与打包

“试渲片段”实际渲染 1280×720；“4K 候选导出”实际渲染 3840×2160，结果属于内部候选，等待审核。上下对照的原片在上、白模在下；4K 对照画幅为 3840×4320。低分辨率原片只在参考栏放大，白模栏来自原生渲染。

后台任务使用独立保存副本，不覆盖原工程。输出目录保存 `job.json`、可编辑 `scene.blend`、必要依赖、PNG 帧、两份影片及内部检查记录。两片使用同一份原声编码。依赖缺失、帧损坏、来源变化或编码失败会保留具体错误。

“请求停止”会在帧或媒体检查点停止，可能需要等待当前步骤结束。关闭面板不会取消后台进程。长任务应在关闭 Blender 前先确认结果或请求停止。

技术核验检查帧数、时间戳、尺寸、实际码率、完整解码、音轨及来源 SHA。**技术通过不能证明动作、站位和镜头符合原片**；视觉状态默认“未核验”。生产负责人仍须检查当前保存后重开的工程及实际影片。

完成 4K 候选导出后，还须提供**当前工程与原视频的同帧骨骼重合审核**：填写协议、报告及本片稳定角色编号，并在偏好设置指定主技能的叠加检查脚本。正式打包会重新在线检查主技能，用当前任务的工程 SHA、原视频 SHA、真实帧段和角色集合调用统一检查器。缺证据、未审核、审核失败或来源变化都不能生成交稿包；预览也不能打成交稿包。检查器核对证据完整性及视频结构，实际动作和叠加画面仍须由检查者真实观看，不能用填写“通过”代替。

客户 ZIP 只收集本次登记的工程、必要依赖、两份影片和中性使用说明。内部 QA、审核素材、失败记录、日志及缓存留在任务目录。包内成员、CRC 和逐文件 SHA 在本机核验。客户模型规范只在明确选定该文件时附上；私有模板库不会自动入包。

## 动作辅助

插件偏好指定已安装的 `video-to-3d-previz` 的 `scripts/motion/motion_workbench.py` 和 `scripts/check_update.py`。可以打开现有任务，也可以在面板选择本机角色模板、模板绑定配置、动作后端配置，按订单参考视频和帧段新建任务。已有 BVH 时可显式选择该输入。

“查看动作状态”会在后台执行在线更新检查，再查询任务。失败门禁不会放行动作步骤。“继续动作辅助”只执行当前同任务返回的受限下一步；不会自动写入人工验收通过。当前 GEM 默认识别单个主要人物，多人身份和遮挡必须另行核验。

导入前先重新查询状态，再点击“导入动作候选参考”。插件只追加任务登记、来源 SHA 一致的候选人物到独立参考集合，默认不参与渲染；锚点指定放置对象，留空用 3D 游标。它不替换生产角色动作，也不替你处理脚地、手物接触或多人站位。状态及导入的实际限制以面板结果为准。

## 固定角色配色

外部配色 JSON 按稳定 `actor_id` 管理，明确列出对象名及身体/标记材质槽。修改身体颜色后点击“应用配色”；标记可指定线性 RGBA 或 `complement` 自动互补色。自动算法先转为显示 sRGB 计算相反色相，再转回 Blender 线性颜色；灰色等低饱和底色使用稳定有色回退，仍需看实际画面辨识度。见 `examples/palette.json`。

复制示例到自己的订单目录，替换示例对象名和槽索引。编号与对象映射须经人工核对，不能把检测顺序当身份。插件为目标角色隔离材质，保留网格和面分区；只对明确指定的颜色槽操作。存在不能安全替换的颜色链接时会报错，不会声称已上色。配色操作不会自动改变三片现有工程；应用后自行检查并保存新版本。

## 当前边界

链接的外部 `.blend` 库尚不支持自动迁移，须先在副本中本地化。首版也拒绝启用布料、软体、流体、粒子、动态绘画、海洋或刚体模拟的工程，避免遗漏模拟缓存；不要直接删除生产模拟来消除提示，应在独立副本中准备适合交付的烘焙结果。合成器中的 File Output 节点会被拒绝，避免后台渲染写到任务目录外。导出工具保留工程原有数据；交稿前由负责人核查工程内部文本、路径和客户要求。工作流、算法运行环境和权重在插件之外安装；插件不自动下载权重或调用付费服务。

测试安装使用独立的 E 盘 Blender 用户目录，保留正常启动的用户配置。Blender 官方支持通过 `BLENDER_USER_RESOURCES` 指定独立用户目录，详见[目录布局说明](https://docs.blender.org/manual/en/latest/advanced/blender_directory_layout.html)。安装 ZIP 本身不写系统环境变量。

本插件用于减少重复导出和来源核验工作。三片正式返修、动作准确率和最终整包须分别验收。
