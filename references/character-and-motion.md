# 人物画风、动作与三维检查

## 画风基线

以当前用户提供或已确认的参考为准，建立样式小样并在实际渲染检查。不要因“白模”一词自行把所有人物变成白色，抹掉任务要求的身份色。

本来源项目采用：球形头、块状身体、角色身份色、球面眼睛高度的短色条、前胸贴面矩形；去掉鼻块、凸起眼罩、镜框、环绕头带、头发圈、辫子与突出球形关节。这是该项目的样式案例，新任务未指定时不能强制套用。

眼条要检查头部局部坐标与最终机位：稍高于球头中心的眼区，不能落在嘴部；随头转动，不穿透球面显示到后脑。胸标跟随身体正面，只在胸前出现，不能为了背面镜头“看得到”而复制到背部。

### 球面眼条与头身连接

短眼条应沿球面弯曲贴合。优先使用头部材质分区/纹理；独立网格须有足够细分并贴合头部实际表面，可用正确设置的 Shrinkwrap 或球面投影。整块平板平移到球前方，即使中心接触、正面看不出缝，侧边仍会悬浮，不算贴合。只允许为避免深度冲突所需的微小表面偏移，不能做成有明显厚度的立板、眼罩或支架。

在正面、侧面、斜视/转头中间姿态与实际交付机位检查：眼高、短条轮廓、边缘离面、厚度、随头变换和后脑漏显。修复不应通过自动朝相机、加宽环绕或额外发光掩盖。已有认可邻近模型时，先读取其几何/材质和头部变换，再按目标球面适配，不能盲复制旧的世界坐标偏移。

是否有颈部由当前任务已确认样式决定，不用历史案例替代当前合同。本轮明确要求**无外露独立颈柱**时：球头下部与躯干顶部保持自然衔接，不留可见空气缝，也不加圆柱脖子“补连接”。通过校准头身位置、尺寸、头部枢轴、父级/约束和必要的内部连接修复；内部连接不能在转头、俯身后露成新脖子。只删除颈柱却留下浮头同样失败。骨骼相连不代表表面相连，不能用拉长头部或大幅埋头毁坏认可比例。其他项目明确有脖子时按其参考，不套用无颈禁令。

来源色板语义：主角红、第二角色蓝、第三绿、第四黄；前景棕、背景灰、远处交互物粉、近处交互物橙、光源白、其他特殊对象紫。环境语义色仅在任务选择该模式时使用，已要求原片还色则按[场景主色](reference-and-camera.md)处理。跨镜保持身份稳定，人物/场景/主要道具可区分；标志性道具原色在不影响区分时保留。实际色值从用户素材取样或登记选择，不凭文字假定精确RGB。

采用这套角色色板时，第四角色在所有镜头及模型实例中统一为黄色，不能沿用旧实例的其他身份色。用户明确另选色板时遵循新选择。身份色与眼部/胸前焦点标记色是两种属性：黄色人物不等于黄色标记。

## 焦点标记自动选色

眼部短条、前胸矩形等焦点标记**不再预设为黄色**。每次创建标记、替换人物材质或修改身份色，都重新读取实际底色并计算；不得仅按角色名、旧缓存或预览窗口颜色猜测。

1. **检测承载表面。** 眼条读取头部相邻面的底色，胸标读取胸前衣身的底色；两者不同就分别评估。读取实际使用的材质槽、着色节点或纹理覆盖区域，不能把未连接到着色器的 viewport diffuse_color 当最终底色。采样时排除已有标记自身、反光、遮挡和背景，记录输入值与来源。
2. **统一色彩空间。** 选择并记录用于计算的RGB空间（例如范围0..1的sRGB），将材质线性颜色正确转换到该空间后计算候选，写回材质时按相应传递函数转回线性值。不能混用线性RGB与显示RGB，也不能把渲染后的截图颜色当作可直接反演的材质颜色；项目的视图变换、灯光与曝光效果在实际交付渲染中另行复核。
3. **计算互补候选。** 对有明确色相的底色，转为HSV后取 `H_mark=(H_base+0.5)%1`（色相旋转180°）；以该色相生成候选，再调整饱和度和明度，得到既与底色相对又有足够亮暗差的标记。不能把“色相不同”直接算作可辨识，也不能机械地对RGB做1-R、1-G、1-B后立即通过。
4. **检查亮暗并回退。** 同色相的候选可先选更深或更浅的版本；对灰色、黑白等低饱和底色，不使用无意义的色相反转，改用与底色亮度相反的深色/浅色。若有色互补候选仍无法清楚分离，使用黑/白高对比回退，并记录理由。建议把相对亮度对比比值3:1作为工程初筛目标，定义为 `(较亮L+0.05)/(较暗L+0.05)`，L从同一显示色空间按正确转换计算；这是本技能的初筛建议，不是动画视觉通过或无障碍认证。小面积标记、强阴影和远景还要看实际图。
5. **冻结稳定映射。** 按角色ID、承载材质与标记类型记录底色、最终标记色、算法版本、亮度对比、回退原因。同一底色跨镜复用同一结果；灯光和阴影变化不触发逐帧跳色。底色确实变更时重新计算，若底色有动画，先确定稳定的分段或全段方案，不能让标记每帧在黑白/互补色之间闪烁。
6. **验证实际成片。** 检查近景、远景、阴影、侧视及跨镜切换中的眼条和胸标是否清楚。保持眼睛高度、贴面形态和前胸位置，不用加厚眼罩、额外发光、在背部复制标记等方式补偿配色问题。交付时从当前保存工程重新渲染，核对两份视频确实使用了新配色。

典型检查：黄色角色的标记通常从蓝色方向选候选，再选足够深的蓝；蓝色角色从橙黄方向选候选；中灰角色选择更深或更浅的中性色。这里只说明计算方向，不是按颜色名称硬编码的查表，最终数值由实际材质与渲染决定。

## 左右、前后与坐标

动作分析先说解剖左/右，再映射骨骼。分别记录“解剖左”“骨骼名”“模型局部轴”“画面左”。来源工程曾出现 `.R` 是解剖左的命名反转，这不是其他工程的通用规则；必须检查静止姿态、局部轴及动作实际投影。

身体朝向由肩、胸、骨盆和支撑点共同决定。头朝左但躯干仍朝镜头，不是“头左身右”的侧身；转头不能代替转体。分别登记根朝向、胸背朝向、头部正面轴和视线目标，眼条随头的真实正面变化，不能总朝镜头。背面镜头先核对身体正反轴，再看胸标是否自然被身体遮挡。

## 取物、托持与交接

- 建立衣襟开口、内层遮挡与足够的衣内空间，先测试手和道具的完整路径。实体腰块会堵住抽出路径，需要与用户简模风格兼容的空腔或衣壳。
- 初始物件若处于衣内，使用真实遮挡让它不可见；不能用藏到画外、缩成0、直接开关显隐来假装完整取出过程。正常剪辑或明确不可见区段可用显隐管理，但不得掩盖要求表现的动作。
- 抽出、下移、转腕分别设阶段；掌心方向、握持点与道具旋转保持一致。空闲手按原片动作，不自动变成双手托物。
- 建立接触之前不把道具硬绑定给接收者；接触期间检查手-物相对关系，转交要连续。原片看不清独占持有或完全放手时，只复刻可证实部分。
- 道具须同时避开衣壳、腰、腿和身体；只测手腕到道具中心的距离不够，中心近不代表表面接触。
- 原片可见的杯子、托盘、包裹等必须建出可辨认轮廓并实际出现，不能以空拳、球手或“手已到位”替代道具。登记持有者、手指/掌托区域、掌心朝向、物件姿态和首次出现时点；视角下被桌面或身体误挡住也算缺失。

## 手型与掌端

以当前用户提供的绑定模型、认可样例和明确纠正锁定腕掌轮廓、掌长、厚度与整体臂长，不能仅凭历史案例禁球手。本轮已明确拒绝用圆球、圆盘或孤立圆团代替手时，简化掌部仍须有方向和可辨认的掌端。若认可模型为连续块状/圆角臂掌，可延续其轮廓，不必擅自添加写实五指；其他项目允许球手时不套用此禁令。

检查肩→肘→腕→掌端的完整长度、关节位置和连接；“手臂覆盖手掌”表示参考要求的臂掌整体轮廓延续至掌端，不能把腕点误当终点，末端另挂一个球，也不能把整块前臂无节制拉长以替代掌部。尺寸以认可模型比例为基准，先冻结后解动作；没有参考数值时记录测得比例及容差，不编造通用厘米标准。

从侧视、正面、握持/挥手/扶物等受影响姿态核对腕掌缝、折断感、掌心方向与接触形状。肘弯曲后仍要连续，终点到位不能抵消上臂/前臂角度、掌形或穿身错误。

## 手臂与伏身

用肩-肘-腕链约束完整轮廓：上臂角度、前臂方向、肘极向、骨段长度、手掌朝向及接触点。不要只用两手重合这一条通过条件。三维肘角和画面投影肘角分别记录。

先校准整镜固定人体比例，再解动作；不要逐帧伸长骨段追手。若旧rig比例不合理，可以明确校准一次固定长度，保留与基线的倍率及理由，不能把校准值称为真人真实尺寸。

伏身和匍匐要共同检查肩胸骨盆、头肩连接、双臂及支撑地面。换胸背方向后，原先被遮住的颈肩间隙可能暴露成“浮头”。优先修真实连接，不加违背画风的厚脖子或把相机挪走。

对非均匀缩放、父子骨骼继承和约束，检查求值结果是否出现剪切、骨段拉长或肘缝；不能只看局部矩阵数值合理。需要改变继承缩放模式时，先在小帧段验证受影响骨骼，不能全rig一键改动。

## 行走与人物互动

行走按根路径、转弯、步频、支撑脚/摆动脚、脚底锁地、重心起伏和摆臂配合检查。禁止用原地摆臂替代位移、脚滑着平移、双脚同步剪刀摆或在动作未结束前停住。对照整段原片正常速度运动及连续帧，首尾站位正确不能证明步态正确。离画和被家具遮挡仍按原片时点发生。

挥手、张臂和贴面致意分别检查起势、接近、动作峰值、保持和收回/分离；身体与头部偏转、肩肘腕掌、左右侧和角色距离分别匹配。贴面致意不能让两颗球头直接相互贯穿，也不能只让两人直立靠近；按原片可见的偏头、躯干倾斜和接触部位复刻，遮挡不清的接触保持不确定。正常遮挡、约定的关节内部衔接与可见穿透分别报告。

穿模范围覆盖自身肢体—躯干、人物—人物、人物—家具/栏杆和手—道具。重点检查接近、首触、保持、分离以及相邻插值帧；不同动作段风险不同，不能只查第一帧。三维检查预先登记模型尺度、间隙/穿入容差、覆盖对象与帧段，结合最终分辨率的可见影响判断，不能把任意网格相交都判为错误或把被挡住的穿透一律放行。

## 原生与画面两条证据

从保存后重新打开的文件获取 evaluated mesh、世界矩阵、骨段端点、相机与显隐，并与渲染联系起来。建议针对风险实际执行：

| 风险 | 检查方式与报告边界 |
|---|---|
| 浮脚/离开走道 | 足底对真实地面/楼板联合区域，覆盖整个行走帧段，不能只对全局 z=0 |
| 撞座椅/栏杆 | 先包围盒粗筛，再对有候选的网格做表面或距离检查；粗筛无候选应报告“无需窄阶段”，不冒称跑过BVH |
| 穿衣/穿腿 | 检查所有相关衣片、身体段和道具；内衬通过不代表外襟通过，BVH交叉不等于已测穿入深度 |
| 断肘/浮头 | 肩肘腕/胸颈头真实连接、表面间隙、骨长随时间变化，并看最终视角 |
| 平板眼/球手/擅加颈柱 | 对照认可造型，检查球面贴合与侧边、腕掌到掌端、头身表面及转动后轮廓；父子绑定或中心距离不够 |
| 人物互穿/贴得过近 | 逐角色检查头、躯干、肢体的表面关系与原片间距，覆盖接近到分离；画面重叠不等于表面接触 |
| 道具早露/丢失 | 实际渲染中逐帧看首次可见、遮挡与持有，可用语义遮罩辅助，注明分辨率和检测阈值 |
| 修A破坏B | 对未授权对象/帧段比较基线的动画、几何、可见性、机位和音轨 |

异常按可见影响、物理程度和用户要求评估，记录帧段与量值。不要通过隐藏问题对象或缩小测试范围制造“零穿插”。
