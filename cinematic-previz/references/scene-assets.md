# 场地一致性与多机位场景参考

先从当前分镜圈定观众会反复看到的固定地标、导演安排的遮挡、拟用机位和运动范围。用一个场地 ID 关联各机位、原图、选版和实际调用。记录固定结构的位置关系、非对称细节，以及本场门扇、植被、照明和天气等状态。同一实景照片出现冲突时，核对拍摄位置和场次，选定本场依据。原始实拍、制作选版和无实拍的新视角推演分别标明来源。局部导览文字或铭牌需要忠实时，复用已核对的原图像素。

固定镜位、近景插入和实拍已覆盖的切镜，优先用图片。大幅绕行或推拉、跨门槛、翻到物体背后以及依赖精确遮挡或通行距离的镜头，按实际风险补拍对应角度或做三维预演。用户限定只用图片时，保留能核对的角度，并记录缺证的区域或调整相应镜头。

## 低成本图片方案

1. **每个选用机位对应一张底图。** 从原始实拍挑与镜头轴线和可见范围一致的照片。全景给布局，同侧近照只补招牌、材质或局部轮廓。每个镜头从原图或已验机位底图起步，避免多代生成层层继承偏差。缺少机位时先找现有实拍、可补拍角度或安排已有视角。确需做近邻新角度，可用最接近的机位图加地标位置线稿，必要时再给相邻图确认新露出的区域。生成角度记录为推演，可核对范围内才能选用。
2. **区分构图和外观输入。** 主图负责本镜门框、地面和遮挡构图，辅图只传指定细节。标记门柱边缘、台阶边、左右不对称地标和人物落脚位，供审图或让实际支持草图的工具读取。干净底图与标注图分别使用。线稿、深度或轮廓图仅在确认目标工具支持对应输入时作为结构参考。输入槽不足时，先把原底图、人物站位和必要局部合成为单张干净首帧，再调用。
3. **用蒙版或图层控制改动范围。** 固定机位保留背景底图，把人物、道具、局部植被和接触阴影放在各自的选区内。同一灌木的稳定位置、树冠和颜色基线沿用该场，局部修过的画面要核对相邻机位。要求背景像素严格保留时，把生成结果按蒙版叠回原底图并核对蒙版外区域。小幅裁切能模拟同视点内的构图收紧，需要真实视差的推进要用对应画面依据。不同视角的建构按原图透视和遮挡验证。
4. **首帧和视频分别判断。** 先对已统一裁切的同机位画面做半透明叠图或闪切，核对门框角、台阶边、基座及非对称地标。不同机位并排核对地标顺序、遮挡和阴影方向。同一镜检视首、中、尾帧及关键揭示点，逐帧观看地标是否滑动或变形。固定机位先保留空景底板，必要时用人物层和遮挡蒙版合成。换机位从对应底图建立首帧，真实续镜按 [尾帧接力](frame-handoff.md) 使用实际出点帧。依关键遮挡或新露出区域无法成立时，回到补拍、三维或有依据的机位。

采用已有模板时，把实际选用的机位底图、版本和用途填进原工作簿对应场景栏，带标记的核对图按需放附表。首帧另按现有首帧栏管理。只替换受影响的图并检查其依赖镜头，摆放与导出复查按 [Excel 实图补齐与摆放](director.md#excel实图补齐与摆放) 执行。

工具依据见 [Runway 图像参考与构图草图](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)、[Adobe 生成编辑选区](https://helpx.adobe.com/photoshop/desktop/make-selections/refine-modify-selections/use-selections-for-generative-editing.html) 和 [Runway 图生视频首帧与运动](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)。能力按实际模型和工具核对。

## 实景测量与三维底模

1. **补齐空间证据。** 以入口、墙角或其他可定位点为原点，记录轴向和单位。量出影响镜头的门洞、地面高差、进深、基座位置和通道净宽，注明实测与估算。复用实拍匹配机位，单张照片配合消失点和已知尺度可近似定位相机。连续补拍时从不同位置取得相互重叠的照片并覆盖关键遮挡两侧，摄影测量按项目所用工具的采集指南执行。 [fSpy 相机匹配](https://fspy.io/tutorial/) · [RealityScan 摄影测量采集](https://dev.epicgames.com/documentation/realityscan-mobile/Photogrammetry-Camera-Movement?lang=en-US)
2. **共享同一场地模型。** 按需要用平面与剖面、简单体块或扫描资产锁定结构和场景状态。固定各镜传感器与画幅设置，记录焦距或视角、机位、机高、朝向与移动路径。同一场次的固定结构和装置沿用世界位置。图生视频从所需机位出首帧，动态引导仅在确认平台支持时采用。精确匹配实拍移动镜头时按实际需要做相机／镜头标定。 [三维预演流程](blender.md) · [Unreal Engine 镜头标定](https://dev.epicgames.com/documentation/en-us/unreal-engine/camera-lens-calibration-overview)
3. **复核空间与运动。** 条件允许时把模型投影分别叠到两个不同机位实拍上，看固定地标能否同时吻合。采样关键运动的起幅、揭示点、落幅，核对运动视差、步道高差、遮挡和可见边界，按需要回放。记录实拍验证、制作估算及当前不可见后方的推演范围；交付在用户要求范围内能复用的场地图、模型、机位图或预演。
